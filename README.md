##  ¿Qué es NEON-PROJEC?

**NEON-PROJEC** es un foro web moderno diseñado para comunidades que buscan un espacio de discusión limpio, rápido y con una estética que rinde homenaje a la era dorada de los foros, pero con la potencia de la web actual.

> *"Un foro no es solo una lista de mensajes; es el latido de una comunidad."*

###  Objetivos del Proyecto
- Crear una plataforma de discusión ligera y personalizable.
- Implementar un sistema de hilos y respuestas con notificaciones en tiempo real (próximamente).
- Ofrecer una experiencia de usuario (UX) que combine lo retro con lo moderno.
